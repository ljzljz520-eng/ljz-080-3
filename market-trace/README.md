# 🥬 菜市场摊位溯源平台

一个完整的三端菜市场食品安全溯源系统：摊主录入进货批次/检测/库存/临期处置，市场管理员扫码巡检与抽检，消费者扫码或查询查看来源公示。

## 快速开始

```bash
npm install
npm run seed     # 初始化演示数据（可选，首次启动会自动建空库）
npm start        # http://localhost:3000
```

## 三端功能

### 摊主端（/owner）
- **进货批次录入**：选商品+供应商，填生产日期/保质期（到期日自动计算）、数量、进货自检结果；自动生成批次号 `PC+日期+序号`
- **检测结果补录**：自检合格/不合格，不合格自动隔离下架
- **剩余库存登记**：销售出库、盘点调整、损耗报损，自动结余并生成库存流水
- **临期处理**：折扣处理（继续卖）/退货/销毁，提交市场核验；系统按"到期日-提前预警天数"自动标临期
- **批次溯源二维码**：可打印张贴，链接指向消费者公示页

### 管理员端（/admin）
- **巡检看板**：全市场批次统计、临期/过期预警、检测不合格批、待核验处置、近期巡检
- **扫码巡检**：摄像头 jsQR 实时识别（也支持手动输批次号），一屏看到"这批菜从哪来→谁检测过→库存与处置"
- **市场抽检**：录入快检结果，不合格自动强制下架销毁并生成巡检记录
- **巡检记录**：正常/发现问题/已整改，含现场处理措施
- **处置核验**：现场确认摊主的折扣/退货/销毁处置
- 全市场批次搜索（批次号/商品/摊位）、摊位名册（含营业执照）

### 消费者端（/，免登录、严格脱敏）
- 按摊位查看在售商品，或按商品名搜索
- 扫码直达批次溯源页：**产地 → 供应商 → 进货验收 → 检测公示 → 销售/处置** 时间轴
- 仅展示公示信息，**不返回**摊主进货价、剩余库存、手机号、内部备注、巡检流水等后台数据（服务端字段白名单脱敏）

## 技术结构
- 后端：Node.js + Express 5，JWT 鉴权（角色：owner/admin），bcrypt 密码哈希
- 存储：零原生依赖的 JSON 文件库（`server/db.js`，数据在 `server/data.json`，便于演示；可平滑替换为 SQLite/MySQL）
- 前端：原生 HTML/CSS/JS，移动端自适应；二维码 `qrcode` 服务端生成 PNG；扫码用本地 vendored `jsQR`（无需外网 CDN）
- 目录：`server/routes/{auth,owner,admin,publicApi}.js`，`public/{index,stall,trace}.html` + `owner/` + `admin/`
