# 🥬 放心菜场 · 菜市场摊位溯源平台

一个覆盖「摊主录入 — 市场快检 — 管理员巡检 — 消费者扫码」全链路的菜市场溯源系统演示。

## 角色与功能

### 🧑‍🌾 摊主工作台 `/vendor/`
- **录入进货批次**：商品、产地/来源地、来源类型（基地直供/农户直收/批发采购/供应商配送）、供货方、数量单位、到货/进货时间、保质期，提交后自动生成唯一**溯源码**
- **录入检测结果**：检测项目、合格/不合格/待检测、检测机构与方式；**一旦录入"不合格"，批次自动召回下架**，消费者端立即不可见
- **每日库存盘点**：更新剩余库存，自动算出售出量并形成流水；库存为 0 自动转"已售罄"
- **临期处理登记**：折价促销、折价售完、丢弃报损、无害化销毁；完结类处理自动扣减库存并改状态
- 查看/打印本批次**溯源二维码**（指向消费者公示页）

### 🪪 管理员巡检端 `/admin/`
- **监管看板**：摊位数、在售批次、临期预警（今明两天到期）、召回批次、最近巡检
- **扫码巡检**：浏览器调用摄像头（jsQR）识别批次二维码，查看该批菜的**完整链路**：
  产地 → 来源类型 → 供货方及联系方式 → 批次数量/剩余库存 → 检测记录（谁抽检、结果、方式）→ 库存盘点流水 → 临期/销毁记录 → 该摊位历史巡检
- **登记巡检**：合格 / 限期整改 / 不合格，填写问题与整改要求；无摄像头时支持手动输入溯源码
- 可看到摊主联系电话、供货方联系方式等内部管理信息

### 🛒 消费者端 `/consumer/`（无需登录）
- 按摊位名/品类/摊位号搜索，查看**在售商品**
- 扫批次二维码打开 `/t/{溯源码}`：商品来源（从哪来）、检测公示（谁抽检、结果）、临期处理记录
- **信息隔离**：公开接口仅返回来源、检测、公示级处理记录；不暴露摊主电话、供货方联系方式、营业执照、库存流水、巡检整改等后台信息；售罄/召回/已处理批次不出现在在售列表

## 技术栈
- 后端：Node.js + Express + better-sqlite3（零外部依赖，数据文件 `data/market.db`）
- 前端：原生 HTML/CSS/JS，无构建步骤；二维码生成 `qrcode`，浏览器扫码 `jsQR`
- 认证：登录后颁发随机 token（存 sessions 表），Bearer 鉴权；角色中间件 + 摊位级越权校验

## 快速开始
```bash
npm install
npm run seed     # 初始化演示数据
npm start        # http://localhost:3000
```

### 演示账号

| 管理员 | `admin` | `admin123` |

示例溯源码：`PC20260930A001`（合格在售）、`PC20260928A017`（临期折价）、`PC20260929B009`（今日到期）、`PC20260929A012`（农残超标召回销毁）。

> 演示系统使用明文密码仅为体验方便，生产环境应改为加盐哈希 + HTTPS。

## 主要 API
**公开（消费者）**
- `GET /api/public/stalls?q=` 搜索摊位（安全字段）
- `GET /api/public/stall/:code` 摊位在售商品
- `GET /api/public/trace/:code` 批次溯源公示
- `POST /api/login` 登录（role: vendor/admin）

**摊主**（Bearer）：`GET /api/vendor/me`、`GET/POST /api/vendor/batches`、`GET /api/vendor/batch/:id`、
`POST .../detection`、`POST .../inventory`、`POST .../handling`、`GET .../qrcode`

**管理员**（Bearer）：`GET /api/admin/dashboard`、`GET /api/admin/stalls`、
`GET /api/admin/trace/:code`（完整后台视角）、`POST /api/admin/stall/:id/inspect`

## 目录结构
```
src/
  server.js    Express 服务与全部 API
  db.js        SQLite schema（含轻量列迁移）
  helpers.js   临期判定、状态文案、公开字段过滤
  seed.js      演示数据（合格/临期/不合格召回等场景）
public/
  index.html        平台首页与三端入口
  consumer/         消费者端
  vendor/           摊主端
  admin/            管理员端（扫码）
  trace.html        扫码落地的公开溯源页 /t/:code
  assets/           样式、通用 JS、jsQR
```
